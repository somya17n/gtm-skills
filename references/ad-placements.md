# Advertising Platform Placement Specs

Reference for ad creative specifications across all major platforms: dimensions, file formats, text limits, and best practices.

---

## Facebook

### Feed

| Spec | Requirement |
|------|-------------|
| **Image dimensions** | 1200x628px (landscape) or 1080x1080px (square) |
| **Aspect ratio** | 1.91:1 (landscape) or 1:1 (square) |
| **File format** | JPG or PNG |
| **Max file size** | 30MB |
| **Video dimensions** | 1080x1080 (square) or 1280x720 (landscape) |
| **Video length** | 1 second to 241 minutes (15 seconds or less recommended) |
| **Video format** | MP4 or MOV |
| **Max video size** | 4GB |

**Text limits:**
| Element | Limit | Recommendation |
|---------|-------|---------------|
| Primary text | 125 characters before truncation | Keep under 125 chars for full visibility |
| Headline | 40 characters | Concise, benefit-focused |
| Description | 30 characters | Supporting detail |
| URL display | Auto-generated from destination URL | -- |

### Stories

| Spec | Requirement |
|------|-------------|
| **Image dimensions** | 1080x1920px |
| **Aspect ratio** | 9:16 (full screen vertical) |
| **File format** | JPG or PNG |
| **Max file size** | 30MB |
| **Video length** | 1-120 seconds (15 seconds recommended per card) |
| **Safe zones** | Top 14% and bottom 20% reserved for UI elements |

**Text limits:**
| Element | Limit |
|---------|-------|
| Primary text | 125 characters |
| Headline | 40 characters |

### Carousel

| Spec | Requirement |
|------|-------------|
| **Card dimensions** | 1080x1080px (square) per card |
| **Number of cards** | 2-10 cards |
| **Aspect ratio** | 1:1 |
| **File format** | JPG or PNG per card |
| **Max file size** | 30MB per card |

**Text limits (per carousel):**
| Element | Limit |
|---------|-------|
| Primary text | 125 characters |
| Headline (per card) | 40 characters |
| Description (per card) | 20 characters |
| URL (per card) | Each card can link to a different URL |

### Reels

| Spec | Requirement |
|------|-------------|
| **Video dimensions** | 1080x1920px |
| **Aspect ratio** | 9:16 |
| **Video length** | Up to 90 seconds (15-30 seconds recommended) |

## Email

### Image Specifications

| Element | Specification |
|---------|--------------|
| **Hero image** | 600x300px (standard) or 600x400px (tall hero) |
| **Inline content image** | 560px wide, auto height (20px padding on each side) |
| **Retina-ready** | Upload at 2x resolution (1200x600 for a 600x300 display) |
| **Alt text** | Required on every image — descriptive, not decorative |
| **File format** | JPG (photos), PNG (graphics with transparency), GIF (simple animation) |
| **Max file size** | < 200KB per image, < 800KB total for all images in email |
| **Background images** | Unreliable — use VML for Outlook support, CSS for others |

### Email-Specific Rules

| Rule | Detail |
|------|--------|
| Total email width | 600px maximum (some clients use 640px) |
| Text-to-image ratio | Minimum 60% text, 40% images |
| Image blocking | Many clients block images by default — email must be readable without images |
| Animated GIF | Supported by most clients. Keep under 500KB. First frame should convey the message (Outlook shows only first frame). |
| SVG | Not supported in email. Use PNG/JPG. |
| WebP | Not supported in email. Use JPG/PNG. |

## Universal Best Practices

### File Optimization

| Practice | Detail |
|----------|--------|
| Compression | JPEG: 80-85% quality. PNG: use TinyPNG or similar. Target < 150KB per image. |
| Format choice | JPEG for photographs, PNG for graphics/text/transparency, WebP for web (not email) |
| Responsive images | Provide multiple sizes with srcset for web. Single optimized size for email. |
| Color profile | sRGB for all digital images. No CMYK. |

### Accessibility

| Practice | Detail |
|----------|--------|
| Alt text | Descriptive alt text on all images. Functional images need functional descriptions. |
| Text in images | Avoid placing critical text in images — it is not searchable, not translatable, not screen-reader accessible |
| Color contrast | Minimum 4.5:1 contrast ratio for text on images (WCAG AA) |
| Motion | Provide option to pause animated content |

### Safe Zones

Always keep critical content (logos, CTA text, faces) within safe zones — areas guaranteed to be visible across all placements:

| Platform | Top Safe Zone | Bottom Safe Zone | Side Safe Zones |
|----------|-------------|-----------------|-----------------|
| Facebook/Instagram Stories | Top 250px (14%) avoid | Bottom 380px (20%) avoid | Full width usable |
| TikTok | Top 150px avoid | Bottom 440px avoid | Side 50px avoid |
| Pinterest | Full image visible | -- | -- |
| Google Display | Keep text centered | Avoid edges | 10% margin recommended |
| Email | Full width usable | -- | 20px side padding |
